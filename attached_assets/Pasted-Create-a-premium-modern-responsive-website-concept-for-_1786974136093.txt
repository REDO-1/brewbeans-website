Create a premium, modern, responsive website concept for **Brewbeans**, a coffee shop located in Gulshan-e-Iqbal, Karachi, Pakistan.

This is a **design/demo concept for a potential client**, so prioritize visual quality, strong UI/UX, and a polished premium feel.

### Brand

* Name: **Brewbeans**
* Business: Coffee shop
* Location: Gulshan-e-Iqbal, Karachi
* Google rating: **4.9/5 from 79 reviews**
* Phone: **+92 311 2463092**
* Food delivery: Foodpanda
* Existing brand logo: use the Brewbeans logo visible in the provided reference image.
* Do not invent a completely different logo or brand identity.

### Design Direction

Create a warm, sophisticated coffee-house aesthetic.

Use:

* Deep espresso brown
* Warm cream/off-white
* Soft beige
* Subtle coffee/caramel accents
* Large elegant typography
* High-quality coffee photography
* Generous whitespace
* Rounded cards and subtle shadows
* Smooth micro-interactions
* Premium editorial-style layouts

Avoid:

* Generic café templates
* Excessive gradients
* Bright colors
* Overly complicated animations
* Cluttered layouts

### UX Requirements

* Fully responsive for desktop, tablet and mobile
* Excellent mobile navigation
* Smooth scrolling
* Sticky navbar
* Clear CTA hierarchy
* Accessible contrast
* Fast-loading layout
* Subtle hover animations
* Smooth section transitions
* Buttons should have clear hover states
* No broken links
* Use reusable components

### Important

This is a **client pitch/demo**, not a production ordering system. Do not build complicated authentication, checkout, payment or backend functionality.

Use realistic placeholder prices where actual menu prices are unavailable.

Use high-quality café/coffee imagery that matches Brewbeans' warm aesthetic.

The final result should look like a **$1,000+ professionally designed coffee-shop website**, not an AI-generated template.

Make the design visually impressive enough that when the Brewbeans owner sees it, they can immediately imagine their actual business using it.
